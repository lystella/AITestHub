# AgentScope 通义千问配置使用说明

## 📁 文件说明

- **`config.json`** - 唯一的配置文件，包含3个核心模型配置
- **`qwen_simple_example.py`** - 简化版使用示例
- **`qwen_quick_start.py`** - 快速启动脚本
- **`README.md`** - 详细说明文档

## 🎯 3个核心模型

1. **qwen-plus** - 主要LLM模型，处理所有文本任务
2. **qwen-vl-max** - 视觉模型，处理图像相关任务  
3. **text-embedding-v4** - 嵌入模型，文本向量化

## 🚀 快速开始

```bash
# 1. 设置API密钥
export DASHSCOPE_API_KEY="your_key"

# 2. 运行快速启动（推荐）
python qwen_quick_start.py

# 3. 或直接运行示例
python qwen_simple_example.py
```

## 💡 使用建议

- 90%的场景只需要使用 `qwen-plus`
- 涉及图像时才使用 `qwen-vl-max` 
- 需要向量搜索时才使用 `text-embedding-v4`
- 这样既经济又高效
