## 📊 智能缓存系统架构

### 缓存层级

```
┌──────────────────────────────────────────────────────┐
│                   请求入口                            │
└────────────────────┬─────────────────────────────────┘
                     ↓
         ┌───────────────────────┐
         │  L1: 精确匹配缓存      │  ⏱️ <1ms
         │  Key: hash(request)   │  💾 内存
         │  TTL: 1小时           │  🎯 命中率: 30%
         └───────┬───────────────┘
                 │ Miss ↓
         ┌───────────────────────┐
         │  L2: 语义相似缓存      │  ⏱️ <100ms
         │  Key: embedding       │  💾 内存+向量库
         │  Similarity: >0.85    │  🎯 命中率: 30%
         │  TTL: 2小时           │
         └───────┬───────────────┘
                 │ Miss ↓
         ┌───────────────────────┐
         │  L3: 组件级缓存        │  ⏱️ <50ms
         │  Key: component_hash  │  💾 Redis
         │  TTL: 24小时          │  🎯 命中率: 20%
         └───────┬───────────────┘
                 │ Miss ↓
         ┌───────────────────────┐
         │  实际计算              │  ⏱️ 30-90s
         │  调用LLM API          │  💰 成本高
         │  保存到所有缓存层      │
         └───────────────────────┘
```

### 缓存收益计算

```python
# 示例: 每日100个请求

  - 缓存未命中: 40次 × 165s = 6,600s (1.8小时)
  - 总耗时: 2.3小时 ⬇️ 63%
  - API调用: 40 × 10 = 400次 ⬇️ 73%
  - 成本: $18 ⬇️ 60%

  - 时间节省: 118小时
  - 成本节省: $810
```
